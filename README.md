## 一句话差异化

**CloakBrowser 有隐身但没有身份和可信度;ego lite 有身份和 agent 界面但零隐身、零隔离、
上不了服务器。把两边的强项放进同一个「档案」抽象里,就得到市场上不存在的东西。**

最大的加速杠杆:ego lite 的 harness 是 **MIT** 许可的,可以直接 fork;
原生层(闭源部分)我们干净室重实现。
