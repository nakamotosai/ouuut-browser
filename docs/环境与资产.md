## 二、凭据

- **存放**:`F:\.secrets\`(Fernet 加密,主密钥 `F:\.secrets\.master.key`)
- **工具**:`C:/Users/sai/.omp/agent/scripts/secrets_manager.py`(**下划线**,不是连字符)
- **系统解释器**:`C:\Python314\python.exe`

```bash
S="C:/Users/sai/.omp/agent/scripts/secrets_manager.py"
python "$S" list                          # 列服务与 key 名
python "$S" read <service> <key>          # 读单个 key → {"service","key","value"}
python "$S" read <service>                # 读整个服务 → {"service","num_keys","keys":{...}}
python "$S" search <query>
python "$S" write <service> <key> <value>
```

本项目用到的 key(仅记名字,**值不入库**):

| service | key | 用途 |
|---|---|---|
| `github` | `github_pat` | `gh` 认证、建仓、推送(`gh auth login --with-token`) |
| `gitea` | `api_token` / `api_url` / `username` / `web_password` | 建 Gitea 仓库、推送 |

**读值的安全姿势**(避免值进入日志/上下文):

```bash
python "$S" read github github_pat | python -c "import json,sys;sys.stdout.write(json.load(sys.stdin)['value'].strip())" > /tmp/t
gh auth login --with-token < /tmp/t; rm -f /tmp/t
```
