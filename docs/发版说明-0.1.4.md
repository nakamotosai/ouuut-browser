# ouuut 0.1.4 发版说明

> 状态:**未发布**。本文是发版说明草稿,发布前需补齐文末「未完成项」。

## 这是什么

一个自带 Chromium 的 agent 浏览器:把「开页面、点、填表、取快照」变成脚本里的几行调用,
每个页面归属于一个 **TaskSpace**,退出时不留孤儿页。

## 这一版改了什么

0.1.4 与 0.1.3 的**浏览器本体完全相同**(604/611 个文件逐字节一致)。差异只有 native 层的 7 个 JS 文件:

| 文件 | 变化 |
|---|---|
| `js/native/binding/egress-guard.mjs` | 出口闸:防止本机代理被非预期用途借用 |
| `js/native/binding/rotation.mjs` | 轮换改为**档案级租约**(ADR-013,仅生产用途) |
| `js/native/binding/release.mjs` | 发布包校验路径 |
| `js/native/bin/launch-args.mjs` | 启动参数拼装 |
| `js/native/bin/ouuut.mjs` | 入口 |
| `js/native/binding/session.mjs` | 会话绑定 |
| `js/native/serve/boot.mjs` | 服务启动 |

也就是说:**这不是浏览器升级,是发布/安全层的一次收紧。**

## 安装

```bat
node tools/install-release.mjs ^
  --package dist\updates\0.1.4 ^
  --dir "F:\apps\ouuut-browser\0.1.4" ^
  --pubkey release\ouuut-release.pub.pem
```

安装器会**先验签、再逐文件校验、最后一次性换名**;任何一步不符就整体不落地。
