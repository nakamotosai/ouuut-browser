## ADR-001 · 许可证 = Apache-2.0

- **日期**:2026-10-24(**用户拍板**)
- **决策**:本项目自有代码采用 **Apache License 2.0**。
- **理由**:相较 MIT,Apache-2.0 含**明示专利授权**;指纹与反检测领域专利密集,
  专利授权条款对企业采用是实质利好。与基底许可兼容(Chromium / ungoogled-chromium =
  BSD-3-Clause,MIT / BSD 代码可并入 Apache-2.0 作品,只需保留归属)。
- **影响**:`LICENSE` = Apache-2.0 全文;`NOTICE` 登记全部第三方归属;
  fork 的 MIT harness 需保留 MIT 文本与版权行。新增依赖受 `docs/法律红线.md` L2 白名单约束。
- **状态**:已定

- **日期**:2026-10-24(**用户拍板**,接受建议)

## ADR-004 · harness 路线 = fork ego lite 的 MIT harness

- **日期**:2026-10-24(**用户拍板**)
- **决策**:**fork `citrolabs/ego-lite` 的 MIT 许可 harness**,自写原生层。
- **理由**:法律最干净(L2 白名单内)、省时最多(省掉几个月的 agent 界面工作:
  JS 批处理、`@ref`/`loc=` 选择器、TaskSpace 生命周期、site-learnings)。
  原生层(Mojo 通道、语义快照、CDP agent host)由我们干净室自己写。
- **代价(已知并接受)**:我们的代码库与上游同源,上游变更可能带来分叉成本。
  **对策**:只依赖其接口形状,不追上游;必要时全量接管。
- **影响**:M2 落地时必须记录 fork 时的上游 commit SHA;`NOTICE` 补 MIT 全文;
  保留 `LICENSES/ego-lite-MIT.txt`。
- **状态**:已定

## ADR-005 · 通道:不暴露 TCP 调试端口,且不主动发 `Runtime.enable`

- **日期**:2026-10-24
- **决策**:自动化通道**不暴露 TCP 调试端口**,且**默认路径不发 `Runtime.enable`**。
- **理由**:[REA B1/B2] ego lite 的主通道是 Mojo/ipcz 私有 IPC,且**未发现其自动化路径
  自动发送 `Runtime.enable`** —— 证明这条路可行。
- **仍开放的部分**:**自研协议(阶段 B / F17)是条件性工作**,判据归 M0。
  若 M0 证明「按住 `Runtime.enable` 已足够」,阶段 B 取消,省下 4–6 周改投档案引擎与服务器化。
- **影响**:任何 PR 不得把 `Runtime.enable` 加回默认路径;抓包证据是 M4 的验收。
- **状态**:已定(其中 F17 的条件性由 M0 裁定)

## ADR-006 · 内核版本策略:滚动跟随 stable,不做 LTS

- **日期**:2026-10-24
- **决策**:内核基线取 **ungoogled-chromium 当前 stable tag**,滚动跟随(约 4 周一版);
  **不做 LTS**;**绝不靠改 UA 假装新版本**(UA 版本号必须 = 内核真实版本)。
- **理由**:
  1. 真实 Chrome 自动更新,**版本陈旧本身就是判别特征**。实测:CloakBrowser 免费档
     UA 报 `Chrome/146.0.0.0`,而 2026-10-24 真实 Chrome stable = **157.0.8103.15**
     (chromiumdash 官方接口)—— **落后 11 个大版本**。见竞品缺点表 C9。
  2. 伪造 UA 版本会与**特性检测**对不上,比版本旧更糟。
- **影响**:**F2(一条命令 rebase)从「维护卫生」升级为「反检测能力」**,
  列为 M1 第一优先级。跟版成本是永久性的,这是本项目最大的长期工程负担。
- **状态**:已定

## ADR-007 · 档案(Profile)是一等公民

- **日期**:2026-10-24
- **决策**:档案是核心抽象,三种 kind 走同一内核同一抽象:
  `real`(导入本机 Chrome,含扩展)/ `persona`(seed 生成、持久演化)/ `disposable`(一次性)。
- **理由**:解决两家共同的空白 —— CloakBrowser 只有一次性假身份,ego lite 只有单一真实身份。
- **影响**:硬隔离是验收项(`cookie 跨档案读写必须失败`)。
- **状态**:已定

## ADR-008 · 无头 / 服务器与桌面同等优先级

- **日期**:2026-10-24
- **决策**:无头与远程能力是**一等公民**,不是附带功能。
- **理由**:ego lite 主动移除了远程能力、锁死在 loopback;CloakBrowser 无头可用但无身份管理。

- **影响**:M5 之前的所有 API 设计都不得假定「本机 + 有桌面」。

## ADR-010 · REA 材料与「转 public」的门

- **日期**:2026-10-24
- **决策**:本仓库**开发期 private**。GitHub 转 public 之前,必须过一道**材料审查**,
  逐项决定以下内容是否移出公开仓库:
  1. `docs/附录B-REA逆向结论.md` / `-原文.md` —— 对 ego lite 二进制的静态分析记录
  2. `re/ego-lite/` —— REA 任务日志与原始输出
  3. `docs/方案-v1-竞品拆解.md` —— CloakBrowser 的实测细节
- **理由**:L1 允许我们**读**并**得出事实**,但 ego lite 的服务条款 §3 禁止逆向。
  在 private 仓库中保留分析记录用于自研,与**对外发布**该记录是两件事:
  后者可能被解读为协助他人逆向、或构成对上游条款的公开挑战 —— 没有必要为此承担风险。
  我们的公开价值是**代码与基准**,不是对别人二进制的分析报告。
- **私人副本留存**:移出后材料转入 `F:\.secrets` 同级私有位置(或本机非仓库目录),
  不删除,以备将来内部查证。
- **影响**:`docs/里程碑.md` 的 M7(分发)验收里增加一条:**public 化的材料审查已过**。
- **状态**:已定

## ADR-011 · 检测基准的方法是「同机同代理对照」,不是绝对分数

- **日期**:2026-10-24
- **决策**:M0 与后续所有检测基准,一律采用**同机、同代理、同时间窗**的
  **对照矩阵**(裸 Playwright / rebrowser 补丁 / CloakBrowser / ego lite / ouuut),
  而不是只报「我们拿了 X 分」。
- **理由**:绝对分数受网络、代理、检测站版本、时间影响极大,不可复现、不可比。
  对照矩阵能把「工具差异」从「环境噪声」里分离出来 —— 这正是我们要回答的问题
  (「按住 `Runtime.enable` 是否已足够」是一个**差分**问题)。
- **影响**:`probe/` 下的脚本必须支持对同一目标批量跑多个被测对象,并同轮输出矩阵。
- **状态**:已定
