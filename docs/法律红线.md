## L1 · 不打包 / 不派生 / 不逆向复制任何第三方二进制

| 对象 | 其许可怎么说的 | 我们的做法 |
|---|---|---|
| CloakBrowser 二进制 | `BINARY-LICENSE.md` 禁止再分发、派生、逆向 | **不打包、不派生、不复制**。只在竞品对照中引用其**公开文档与产品行为** |
| ego lite 二进制本体 | 服务条款 §3 禁止逆向、反编译、派生、修改 | **不打包、不派生、不复制代码** |
| ego lite 的 MIT harness | MIT(允许复制、修改、再许可) | **可以 fork**(L2 允许) |

### 关于我们已经做过的逆向分析(REA)

用户 2026-10-24 明确授权:对本机安装的 ego lite 二进制做**只读静态分析**,
**目的限于理解接口形状与设计取舍**,产出用于**驱动自研内核**。

**边界(必须守住)**:

- ✅ 可以:读符号、读字符串、看模块依赖、得出「它用的是 Mojo/ipcz 私有 IPC」这类**事实**
- ✅ 可以:把结论写成文档,驱动自研设计
- ❌ 不可以:复制代码片段、复制资源、派生出可运行的二进制
- ❌ 不可以:把它的二进制打进我们的产物
- ❌ 不可以:发布任何可还原其实现细节的中间产物

产出物:`docs/附录B-REA逆向结论.md`(结论)、`docs/附录B-REA逆向结论-原文.md`(原文副本)。

## L2 · 只 fork MIT / MPL / BSD 组件

允许的许可白名单(引入前必须核对):

| 许可 | 可否引入 | 义务 |
|---|---|---|
| MIT | ✅ | 保留版权与许可文本(NOTICE 登记) |
| BSD-2/3-Clause | ✅ | 保留版权、条件、免责声明;**不得用其名义背书** |
| Apache-2.0 | ✅ | 保留 NOTICE;若修改文件需标注 |
| ISC / 0BSD / Unlicense | ✅ | 保留许可文本 |
| MPL-2.0 | ⚠️ 可以,但**文件级 copyleft** | 被修改的 MPL 文件须以 MPL 开源 |
| LGPL / GPL / AGPL | ❌ | 与 Apache-2.0 发布目标冲突 |
| 专有 / 自定义限制许可 | ❌ | —— |

**每个新增依赖必须在 `NOTICE` 登记**:名称、版本、许可、上游 URL、用途。
未登记者不得进入构建。

## L3 · 不做自动过验证码、不做未授权认证访问

| 不做 | 说明 |
|---|---|
| 自动过验证码 | 含打码平台、模型识别、行为绕过。**任何形式** |
| 未授权访问金融 / 医疗 / 政务认证系统 | AUP 明文禁止 |
| 撞库 / 批量注册 / 欺诈辅助 | —— |
| 按站点定制的绕过规则库 | 那是灰产产品的形状;我们做通用能力 |

详见 `docs/功能范围.md` §2.1(N1–N5)。
