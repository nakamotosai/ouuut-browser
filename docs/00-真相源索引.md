## 冲突裁决顺序

同一事实在两处出现且不一致时,按此顺序取:

1. `docs/里程碑.md` 里的**实测证据**(跑过的东西)
2. `docs/决策记录.md` 里的**已拍板决策**
3. `docs/功能范围.md`(范围)
4. `docs/方案-v3-终稿.md`(方案)
5. 其余(v1 / v2 / 附录,皆历史)

**发现不一致 → 改掉旧的那份,不要留两个版本。**
